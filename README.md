# On-Ground.ai Call Centre

A frontend recreation of the On-Ground.ai Call Centre application, built as an intern assignment using React, TypeScript, and Vite.

## Features

- Dashboard with call metrics and priority leads
- Lead profile modal with ICP scores, intent, and buying signals
- Call plan with Calls to make, Incoming, and Recent tabs
- Expandable lead details and simulated call/callback actions
- Calendar with month navigation, date selection, and scheduled activities
- Pulse team channels: General, Sales, and Support
- Channel messaging and pinned-card acknowledgement
- Responsive layout and reusable UI components

## Tech Stack

- React
- TypeScript
- Vite
- Lucide React
- Recharts
- CSS

## Prerequisites

- Node.js and npm

## Setup

Clone the repository, then run:

```bash
npm install
npm install lucide-react recharts
npm run dev
```

Open the local URL shown in your terminal.

## Build

```bash
npm run build
```

## Notes

- This is a frontend-only demonstration using sample data.
- Calls and callbacks are simulated; no real phone calls are placed.
- No backend or external database is required.

## AI Tools

AI assistance was used to support implementation, debugging, and documentation. The final code was reviewed and tested locally.

## Known Limitations

- Data is stored in React component state and may reset on refresh.
- No real telephony, authentication, or backend integration is implemented.
